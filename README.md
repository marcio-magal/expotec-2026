# 🚀 EXPOTEC 2026

## Feira de Tecnologia e Inovação

A **EXPOTEC 2026** é uma Landing Page criada para representar uma feira de tecnologia e inovação, reunindo estudantes, profissionais, projetos e pessoas interessadas em novas tecnologias.

O projeto foi desenvolvido como parte do **Desafio 01 — Tire sua Ideia do Papel**, com o objetivo de transformar uma ideia em uma página web responsiva, acessível e publicada na internet.

## 🎯 Objetivo

O objetivo do projeto é criar uma Landing Page para divulgação de um evento fictício de tecnologia e inovação.

A página foi planejada para apresentar:

- Informações sobre o evento;
- Programação dos três dias;
- Palestras e workshops;
- Feira de projetos;
- Galeria de imagens;
- Local e data do evento;
- Informações de contato.

A proposta visual busca transmitir uma identidade moderna e tecnológica, utilizando uma combinação de fundo escuro, elementos em azul/ciano e uma composição minimalista.

---

## 🧩 Estrutura da página

A Landing Page é dividida nas seguintes seções:

### Header

Contém a identidade da EXPOTEC e o menu de navegação para as principais áreas da página.

### Hero

Apresenta a proposta principal do evento, sua data e informações resumidas, além de um botão de chamada para ação.

### Sobre

Explica o propósito da EXPOTEC e apresenta três conceitos principais:

- Conectar;
- Experimentar;
- Criar.

### Programação

Apresenta a programação dos três dias do evento:

- Tecnologia & Futuro;
- Criatividade & Prática;
- Projetos & Inovação.

### Experiências

Apresenta três das principais atividades disponíveis no evento:

- Palestras;
- Workshops;
- Feira de Projetos.

### Galeria

Apresenta três imagens relacionadas ao universo de tecnologia e inovação.

### Localização

Apresenta informações sobre o local e a data do evento.

### Contato

Possui uma chamada para participação e informações para contato.

### Footer

Contém informações institucionais, navegação e links externos.

## ♿ Acessibilidade

Foram aplicadas algumas práticas de acessibilidade no desenvolvimento da página:

- Utilização de HTML semântico;
- Hierarquia adequada de títulos;
- Atributos `alt` descritivos nas imagens;
- Utilização de elementos `<nav>` com `aria-label`;
- Links com foco visível através de `:focus-visible`;
- Uso de `<time>` para horários da programação;
- Uso de `<address>` para informações de localização;
- Suporte à preferência de usuários que utilizam `prefers-reduced-motion`;
- Contraste entre fundo e textos;
- Layout adaptado para diferentes tamanhos de tela.

---

## 📱 Responsividade

A página foi desenvolvida para funcionar em:

## 💬 Prompts utilizados

### 1. Geração da ideia

> "Me ajude com esta tarefa. Comece me fornecendo algumas ideias que eu possa desenvolver."

A partir das orientações do desafio, foram analisadas diferentes possibilidades de projetos para uma Landing Page.

A ideia escolhida foi uma **Feira de Tecnologia e Inovação**, posteriormente denominada **EXPOTEC 2026**.

---

### 2. Desenvolvimento do HTML

> "Desenvolva a 'Evento de Tecnologia'. Primeiro crie o html completo. Faça de forma que não precise adicionar muitas imagens, no máximo 3."

A IA foi utilizada para estruturar o documento HTML5 utilizando elementos semânticos e mantendo a quantidade de imagens limitada a três.

---

### 3. Desenvolvimento do CSS

> "Perfeito, crie o css completo."

A IA auxiliou na criação do arquivo CSS externo, incluindo:

- Identidade visual;
- Layout;
- Cards;
- Tipografia;
- Espaçamentos;
- Efeitos de interação;
- Responsividade;
- Acessibilidade.
